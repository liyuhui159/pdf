# 书名自动检索下载助手（Android V9）

## V9：逐站验证与统一按钮样式

- 每张网站卡片都有「验证」「编辑」「删除」三个等高圆角按钮，主操作为蓝色，编辑为浅色描边，删除为浅红。
- 在网站管理弹窗顶部保留「新增网站」「粘贴网址」，下方提供全选/清空选择；管理区域按手机屏幕宽度适配。
- 单独点击某站「验证」会根据当前输入的书名向该站搜索网址发送请求；没有输入书名时使用公版书名 Pride and Prejudice 作测试。
- 验证分为 **验证通过（找到实际书籍结果）**、**待确认（可访问但无结果、需登录、验证码或限流）**、**失败（HTTP 错误、DNS/超时/SSL 问题）**。**HTTP 200 不直接等同于搜索可用**。
- 逐站独立异步校验，不会因为网络请求卡住界面；状态包含 HTTP 状态码、耗时、结果原因和校验时间，保存后下次打开仍会显示上一次的结果。
- 修改网址后清空旧校验结果；取消保存不写入这次修改。验证仅测试搜索，不自动下载文件，不绕过登录或其他访问限制。
- 增加模拟网站 HTTP 响应与搜索结果识别的自动化测试。



# V8：弹窗式搜索网站管理（2026-11）

主界面将原来的多行“保存模板”输入框，改成「管理网站（勾选/新增）」按钮。点击打开弹窗：

- 每个网站都有独立稳定的 `#01、#02…` 编号和名称、搜索网址。
- 每个网站前都有勾选框，只有勾选的网站才参与“同时搜索全部”和“按顺序优先搜索”，也影响“打开勾选的网站”。
- 支持一键全选/全不选、增加网站、剪贴板粘贴、编辑名称与搜索网址、删除网站。
- 粘贴普通网址时自动补上 `{keyword}` 搜索参数：识别 Gutendex、Project Gutenberg 的正规搜索地址；识别已有搜索参数 `q` / `search` / `query` / `keyword` / `wd` 等并替换其值。
- 对未知网站使用 `?q={keyword}` 作为**可编辑的推测**并显示提醒，不能保证每个第三方网站的搜索参数都相同；需要时在“编辑”里修改为网站实际地址。
- 所有站点名称、网址、编号及是否勾选单独保存；首次升级从旧版模板文本自动迁移。
- “管理网站”弹窗点击「保存并关闭」后生效，点「取消」不会保存本次更改。

## 如何测试 V8

1. 点击「管理网站」，先取消选中一个默认站点，点击保存；主界面应显示「已勾选 1 / 2 个网站」。
2. 再进入弹窗，使用「粘贴并添加」，粘贴你有权限使用的网址，例如 `https://gutendex.com/`，会显示自动补全搜索 URL；如果重复则提醒，不会重复创建。
3. 添加一个不熟悉的普通网址，检查是否出现 `?q={keyword}` 的黄色提醒，并在编辑中改成该站的真实搜索参数。
4. 关闭、重新打开 APP，确认选中状态和编号保留。

## V7：修复“能搜到却无法下载”

1. 默认提供 **Gutendex**（Project Gutenberg 电子书目录 API）和 **Project Gutenberg** 网页搜索。旧版 example.com 默认占位模板自动迁移；用户保存的其他模板保留。
2. 自动解析 HTML 搜索结果、书籍详情页、下载页和文件链接。点击**解析并下载**后，最多继续分析 3 层、12 个页面，不会无限爬取。
3. 支持常见链接属性 a[href]、data-href、data-url、iframe[src]。网页登录分析器可读取 JavaScript 渲染后的 DOM。
4. **在下载前检查真实响应类型**，不会将登录页面、HTTP 错误页、HTML 下载页简单改名为 PDF。
5. 登录下载保留目标域名的 Cookie、User-Agent 和页面 Referer，并显示系统下载状态、完成信息及错误代码。
6. 对网页倒计时下载按钮，只在页面按钮实际可用时尝试点击，不处理验证码或绕过付费限制。

## 使用步骤

1. 打开 APP，输入书名或读取剪贴板。
2. 保留默认的公版书源，或填写你有权限访问的搜索页，每行一个 URL 模板，必须使用 {keyword} 占位。
3. 点击**同时搜索全部**或**按顺序优先搜索**。
4. 搜索结果中点击**解析并下载**。程序尝试进入相关详情页找到真实 PDF、EPUB、TXT、ZIP 等文件 URL。
5. 如果链接验证成功，Android 系统下载器将文件保存到 Download 文件夹，并由日志反馈进度与实际完成情况。
6. 如果提示未获得真实下载地址，点**打开网页**，到**网页登录分析器**登录/进入详情页/点击网站允许的下载按钮，然后分析当前页。

## 默认模板

```text
https://gutendex.com/books?search={keyword}
https://www.gutenberg.org/ebooks/search/?query={keyword}
```

Gutendex 提供 Project Gutenberg 电子书目录及文件格式链接。并非每个网站都会允许机器人检索或提供可直接使用的下载链接。

## 编译

仓库 `.github/workflows/build-apk.yml` 会运行 Java 单元测试和构建 Debug APK。GitHub Actions 成功后从对应工作流运行的 Artifacts 下载 `book-auto-downloader-debug-apk`；也可用 Android Studio 打开仓库。

## 限制及合规

仅用于自有、获授权、公版、开源或其他明确允许下载的电子书及资料。程序不绕过 DRM、验证码、付费墙或其他访问控制。动态 blob:/data: 链接、跨站点会话、受保护下载接口可能需要在网站内手动操作。
